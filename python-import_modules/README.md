# Python - import & modules

This project covers the basics of importing functions, modules, command line arguments, and built-in functions in Python 3.

## Tasks
* **0-add.py**: Import a simple function from a simple file
* **1-calculation.py**: Import multiple functions from a calculation module
* **2-args.py**: Print command line arguments count and list
* **3-infinite_add.py**: Calculate the sum of command line arguments
* **4-hidden_discovery.py**: Print all names defined by a compiled module
* **5-variable_load.py**: Import a variable from a file
